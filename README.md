# CerebraQuant Solutions — Website V2 (12 Nov 2026)

A premium static bilingual website, designed for free GitHub Pages hosting.

## Preview
Open `index.html` in Chrome or Safari. The English version is under `en/index.html`.

## Pages
- index.html — homepage / three equal pillars
- technologies.html — proprietary quantitative technology and commercial models
- rd.html — scientific R&D and consulting in France
- academy.html — live training catalog with working filters
- research.html — publications and founder background
- contact.html — contact options and email composer (mailto only)
- mentions-legales.html and confidentialite.html — legal/privacy **drafts**
- en/ — translated equivalents
- assets/ — CSS, JS, artwork and the course-cover logo reference

## GitHub Pages
Create a **public** repository, upload the *contents* of this folder to the repo root, then Settings → Pages → Deploy from a branch → main / root. A public repository exposes website source code. Never upload proprietary algorithms, credentials, or private files.

## How the contact form works
It creates a mailto link locally. No database/backend, and no direct email is sent without the visitor confirming in their email client.
